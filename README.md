# Functional Analysis Lab: Cases 3 and 7

Материалы к лабораторной работе по функциональному анализу.

## Состав

- `main.tex` — LaTeX-исходник отчета.
- `src/run_experiments.py` — скрипт для воспроизведения расчетов, таблиц и графиков.
- `figures/` — готовые изображения для отчета.
- `results/` — численные результаты в CSV.

## Воспроизведение

```bash
python3 -m pip install -r requirements.txt
python3 src/run_experiments.py
```

После запуска обновятся файлы в `figures/` и `results/`.
